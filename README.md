# Computer Vision for UAV Autopilot

This repository contains lab assignments and project work for the UAV (Unmanned Aerial Vehicle) course 2024.
The course focuses on drone control systems, computer vision applications, and real-time image processing using Python and OpenCV. The labs cover a range of topics from basic image processing to advanced drone navigation and control.

## Detailed Contents

### [Lab 1: Image Processing Basics](Lab1/)
- Basic image manipulation using Python and OpenCV
- Image loading and display
- Basic image transformations
- Multiple Python scripts demonstrating different image processing techniques
- Implementation of fundamental image processing operations

### [Lab 2: Histogram and Image Enhancement](Lab2/)
- Image histogram analysis and equalization
- Image enhancement techniques
- Implementation of various image processing algorithms
- Practical applications with real images
- Brightness and contrast adjustment

### [Lab 3: Object Detection XML Configuration](Lab3/)
- Introduction to object detection
- XML configuration for detection parameters
- Implementation of basic detection algorithms
- Working with OpenCV detection frameworks
- Application of detection to sample images

### [Lab 4: Tello Drone Basic Control](Lab4/)
- Introduction to the DJI Tello drone platform
- Basic drone control and communication
- Setting up the Tello SDK
- Keyboard control interface implementation
- Video stream processing from the drone
- UI development for drone control

### [Lab 5: Drone Navigation and Control](Lab5/)
- Advanced drone navigation techniques
- Implementing control algorithms
- Path planning and execution
- Real-time video processing from drone
- Integration of control systems with video feed
- Autonomous navigation fundamentals

### [Lab 6: Midterm Preparation](Lab6/)
- Comprehensive review of drone control systems
- Integration of previous lab components
- Enhanced UI for drone interaction
- Preparation for midterm exam requirements
- System testing and optimization
- Advanced control feature implementation

### [Midterm Exam: Tello Drone Control System](mid/)
The midterm exam focuses on developing a control system for the DJI Tello drone. Key components include:
- Drone flight control interface
- Video stream processing
- Keyboard control implementation
- Custom UI for drone control
- Real-time video feed handling

### [Lab 7: Face and Pedestrian Detection](Lab7/)
- Implementation of Haar Cascade classifiers
- Face detection algorithms
- Pedestrian detection systems
- Real-time object detection applications
- Integration of multiple detection types
- Performance optimization for detection algorithms

### [Lab 8: YOLO Object Detection](Lab8/)
- Introduction to YOLO architecture
- Implementation of pre-trained YOLO models
- Video processing with YOLO detection
- Object tracking in video streams
- Custom object detection implementation
- Performance analysis of detection systems

### [Lab 9: Advanced Drone Control with Computer Vision](Lab9/)
- Integration of computer vision with drone control
- XML configuration for drone-specific detection
- Autonomous flight based on visual inputs
- Advanced control algorithms
- Object following and tracking with drone
- Comprehensive drone application development

### [Lab 10: Final Exam Preparation](Lab10/)
- Final system integration
- Advanced drone control features
- Comprehensive testing methodology
- Performance optimization
- Preparation for final exam requirements
- Final application development and testing

### [Final Exam: Advanced Drone Vision and Control System](final/)
The final exam extends the drone control system with advanced computer vision capabilities:

Features:
- Face detection using Haar Cascades
- Object detection using YOLO
- Custom model integration (ONNX format)
- Advanced drone control algorithms
- Real-time image processing

Key components:
- Object detection and tracking
- Advanced flight control
- Computer vision integration
- Custom UI improvements
- Multiple detection models

## Getting Started

This repository contains various lab assignments and projects related to UAV development and implementation. Each directory contains specific assignments and their related resources.

### Prerequisites

Please ensure you have the following dependencies installed:
- Python 3.x
- OpenCV
- DJITelloPy
- NumPy
- PyYOLO (for object detection labs)
- Additional requirements specific to each lab/project (check respective directories)
